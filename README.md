# Cadastro de Loja em C

Sistema de cadastro de produtos desenvolvido em linguagem C para uma atividade acadêmica.

 Funcionalidades
- Cadastro de produtos com ID automático.
- Listagem de produtos.
- Alteração e exclusão.
- Busca por nome e categoria.
- Verificação de produtos duplicados.
- Ordenação por nome e preço utilizando Bubble Sort.
- Exportação de dados para CSV.
- Armazenamento em arquivos de texto.

 Tecnologias utilizadas
- Linguagem C
- Struct e vetores
- Ponteiros
- Manipulação de arquivos
- Bubble Sort
- Switch/Case

 Como executar

Compile com GCC:

```bash
gcc cadastro_loja.c -o cadastro_loja
```

Execute:

```bash
./cadastro_loja
```

Projeto desenvolvido para fins acadêmicos e de aprendizado da linguagem C.
